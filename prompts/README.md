# The four teammates, as plain text

Each `.txt` file is one teammate. No setup, no install.

**To use one:** copy the whole file and paste it into Claude as your Project's
custom instructions, or as the first message of a new conversation. Then give it
your material.

**Run them in this order**, passing each one's output to the next:

```
1-ethnographer  →  your raw material  →  a field note with ranked frictions
2-designer      →  one friction        →  three ritual specs
3-skeptic       →  the top spec        →  SHIP / REVISE / RETIRE + kill criteria
4-prototyper    →  a SHIP verdict      →  cohort, owner, retirement date, kit
```

If the skeptic says **REVISE**, it will name exactly one defect. Give that defect
back to the designer, get a v2, and run the skeptic again. Two bounces maximum —
a third means you picked the wrong friction, not the wrong ritual.

## You sign it, not the agent

Each of these ends its output with a blank sign-off block. Fill it in before
you pass the artifact on — what you changed, and what the next seat should not
take on faith. If you changed nothing, write "nothing". That is allowed, and it
is worth seeing in your own handwriting.

## One thing to watch

The skeptic will approve too much. These models are agreeable by default. Keep a
tally of its verdicts — if it has said SHIP five times running, that's a finding
about the tool, not a run of brilliant designs.
