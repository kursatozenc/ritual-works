# Invite one teammate

These four prompts let you work with one Ritual Works specialist in an ordinary
AI conversation. No installation or agent software is required.

1. Open a new conversation in the assistant you already use.
2. Copy the complete text of one teammate prompt into the conversation.
3. Answer the teammate's opening question.
4. Complete the human fields in its handoff card.
5. If you continue, give the result and completed handoff to the next teammate.

## The four seats

- [`observer.txt`](observer.txt) — turns real notes into an evidence-grounded
  account of what is happening.
- [`designer.txt`](designer.txt) — develops three small practices for one moment
  the person selected.
- [`challenger.txt`](challenger.txt) — tests assumptions, consequences and
  conditions for stopping.
- [`experimenter.txt`](experimenter.txt) — prepares a bounded trial and later
  helps interpret evidence from what really happened.

For the shared purpose, boundaries and decision rights, read the
[`Team Constitution`](../TEAM-CONSTITUTION.md). For a blank transfer between
teammates, use the [`handoff card`](../HANDOFF-CARD.md).
